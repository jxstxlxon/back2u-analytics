So funktioniert die Live-Verbindung

Das Dashboard zeigt historische Exportdaten und lädt über /api/snapshot die zuletzt an Cloudflare D1 übertragenen API-Daten. Google Apps Script sendet YouTube- und Instagram-Werte in regelmäßigen Abständen. Der Übertragungsschlüssel bleibt in Script Properties und Cloudflare-Secrets; dein Browser erhält nur Statistikdaten. TikTok-Sandboxdaten werden nach der Autorisierung separat über die Display API synchronisiert; die älteren Studio-Screenshots bleiben zur historischen Einordnung erhalten.

Solange die Webseite nicht mit dem Worker veröffentlicht wurde, bleibt sie eine lokale Momentaufnahme.
